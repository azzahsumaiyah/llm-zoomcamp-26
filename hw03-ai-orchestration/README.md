## 📖 Key Concepts Learned

### Context Engineering

Providing AI with the right context so it can generate accurate and reliable workflow definitions.

### Retrieval-Augmented Generation (RAG)

Instead of relying only on pretrained knowledge, the model retrieves relevant documents first before generating an answer.

### AI Agents

AI systems capable of reasoning, choosing tools, and completing tasks autonomously.

### Multi-Agent Systems

Multiple specialized AI agents collaborate to solve complex problems.

### AI Orchestration

Using Kestra to automate AI-powered workflows by coordinating prompts, tools, APIs, and agents.
